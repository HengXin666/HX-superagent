# 面板实现计划 v6 (开发总监)

日期: 2026-11-15 02:00 CST · 工作目录: /home/hx/Loli/code/HXLoLis/components/HX-superagent · 上一版: docs/panel-v5-plan.md

## 意图

1. **前置不再是卡点.** 基线提交和 git 由你在本机处理, 所以 v5 的线1(基线收口)和解阻计划作废, 各线直接在当前分支 feat/panel-v2 的工作树里写.
2. **直接落盘.** 产物必须经 hxoa 写进工作目录, 不是留在会话或执行者本地.
3. **把实现做完.** 不再重新设计, 按已定方向做到能用: 预设自定义 + 多选叠加、所见即真实、现代设计语言、系统地图 + 监控台.
4. **回话带路径.** 每条线回报列出所有改动文件的绝对路径.

由此带来的约束: 执行方不能跑检查, 所以测试要写到用户本机一次能跑通; 新增一条线5 专门做跨线静态核对和本机执行清单, 替代原来的"实机集成".

## 相对 v5 的变化

- 原线1 基线收口 → 改为 **实时数据底座**(健康事件补发、执行位标识透传、删除事件、前端共享订阅层), 因为线3、线4 都依赖它.
- 原线3 拆掉数据层部分, 只做设计语言、交互流程和页面迁移.
- 原线5 实机集成 → **跨线核对与交付报告**, 实机部分由你在本机按剧本跑.

## 顺序

线1 先行; 线2 与线1 并行; 线3 依赖线1; 线4 依赖线1、2、3; 线5 最后.
